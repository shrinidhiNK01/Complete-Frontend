## 10. Interview Questions
- **Q1:** What is ARIA and Accessibility?
  *Answer:* It represents a core presentation standard used to control browser layouts and accessibility trees.

---

## 11. Best Practices
- Always use semantic layouts.
- Focus on responsive alignments.

---

## 12. Common Mistakes
- **Mistake:** Hardcoding height and width values in absolute pixels.
  *Solution:* Use relative units like rem, em, or percentages.

---

## 13. Performance Notes
Ensure minimal paint overlays. Avoid using expensive filters on large background images.

---

## 14. Accessibility Notes
Always ensure text elements meet WCAG AA minimum color contrast ratio of 4.5:1.
