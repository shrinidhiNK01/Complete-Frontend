# Frontend Complete Mastery: HTML, CSS, and Tailwind CSS Encyclopedia

Welcome to the ultimate learning repository for Frontend Architecture, CSS design systems, semantic HTML markup, accessibility implementations, and custom Tailwind configurations.

## 📁 Repository Overview

- **`00-Internet-And-Web-Fundamentals/`** — Study guides on DNS routing, Critical Rendering Paths, DOM/BOM architecture, SSL, and CDN routing models.
- **`01-HTML/`** — Document structures, custom web components, shadow DOM nodes, ARIA, and microdata/schema configurations.
- **`02-CSS/`** — Specificity, box models, pseudo-selectors, transitions/transforms, ITCSS/BEM systems.
- **`03-Responsive-Design/`** — Fluid grids, responsive viewport typography, and modern Container Queries.
- **`04-Flexbox/`** — Container/item configurations, pricing card structures, and navbars.
- **`05-CSS-Grid/`** — Repeat parameters, auto-fill, auto-fit, minmax, and Magazine layouts.
- **`06-Animations/`** — Loading skeletons, glassmorphism neumorphic components, and transitions.
- **`07-TailwindCSS/`** — Custom configurations, plugin utilities, and theme extends.
- **`08-Accessibility/`** — Color contrasts, ARIA rules, and screen reader patterns.
- **`09-Performance/`** — Gzip compression, Brotli, deferred CSS configurations, and responsive images.
- **`10-Design-Systems/`** — Typography tables, token engines, design components.
- **`11-UI-Components/`** — Accessible navigation components, modals, calendars.
- **`12-Landing-Pages/`** — SaaS layout frontends.
- **`13-Dashboards/`** — Metric dashboard frontends.
- **`14-Enterprise-UI/`** — Console frontends.
- **`15-Projects/`** — Personal portfolio and ecommerce UI codes.
- **`16-System-Design/`** — CSS theme design engines.
- **`17-Interview-Preparation/`** — Comprehensive HTML, CSS, and Tailwind lists.
- **`18-CheatSheets/`** — Quick code references.
